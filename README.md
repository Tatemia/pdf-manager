# PDF Manager

**Программа для управления PDF-документами «PDF Manager»**, версия 1.0

PDF Manager — настольная программа для повседневной работы с PDF: собрать
документ из нескольких файлов или сканов, удалить, повернуть и переставить
страницы, разделить файл на части, поставить пароль, уменьшить размер,
пронумеровать страницы, извлечь текст и картинки.

Всё выполняется на вашем компьютере: документы никуда не отправляются,
интернет программе не нужен.

---

## Быстрый старт

1. Возьмите готовый файл `PDF Manager.exe` (если проект скачан с GitHub —
   на странице Releases; собрать его самостоятельно можно по инструкции
   в конце) и положите в любую папку — подойдёт и флешка.
2. Запустите его двойным щелчком. Устанавливать ничего не нужно, права
   администратора не требуются.
3. Слева выберите нужное действие, укажите файл и нажмите кнопку
   сохранения внизу окна.

> **При первом запуске** Windows может показать окно SmartScreen
> «Система Windows защитила ваш компьютер». Так бывает со всеми программами
> без цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае».
>
> Запуск занимает несколько секунд: программа распаковывает свои файлы
> во временную папку и удаляет их при закрытии.

**Требования:** 64-разрядная Windows 10 или 11, от 256 МБ свободной памяти.

## Как устроена работа

Окно разделено на две части: слева — список действий, справа — настройки
выбранного действия и кнопка сохранения внизу.

Почти каждое действие проходит одинаково:

1. **Выберите файл** кнопкой «Выбрать…» (в разделах объединения — «Добавить»).
   Файлы можно просто **перетащить мышью** в окно.
2. **Укажите страницы и настройки.** Ошибки в номерах страниц подсвечиваются
   сразу, до запуска.
3. **Нажмите кнопку сохранения** и выберите, куда записать результат.

Исходный файл **никогда не изменяется**: результат всегда сохраняется в новый
файл. Сохранить результат поверх исходного программа не даст. Если вы
перезаписываете какой-то другой существующий файл, а сохранение прервётся
(например, закончится место на диске), прежний файл останется целым.

После каждой операции программа показывает итог. Если что-то получилось
не полностью (например, у части страниц не удалось извлечь текст), об этом
будет сказано в итоговом окне под заголовком «Обратите внимание».

### Как записывать номера страниц

| Запись | Что означает |
|---|---|
| `5` | одна страница — пятая |
| `1,3,7` | страницы 1, 3 и 7 |
| `2-6` | страницы со 2-й по 6-ю |
| `1,4-6,10` | можно сочетать |
| *пусто* | все страницы (там, где это уместно — подсказка под полем) |

Не хотите вводить номера — нажмите **«▦ Выбрать по миниатюрам»**: откроется
окно с уменьшенными страницами, отметьте нужные галочками и нажмите
«Применить». Есть кнопки «Выделить все», «Снять все» и «Инвертировать».

## Возможности

### Объединение

**Объединить PDF** — собрать один документ из нескольких файлов.

1. Нажмите «＋ Добавить файлы» или перетащите PDF в окно.
2. Расставьте файлы в нужном порядке стрелками ↑ ↓, лишние уберите крестиком ✕.
3. Если из файла нужны не все страницы, впишите их в поле «Страницы»
   у этого файла. Пустое поле — весь файл.
4. Нажмите «💾 Сохранить объединённый PDF».

Флажки над списком:
- **«Создать закладку на каждый файл»** — в оглавлении готового документа
  появится закладка с именем каждого исходного файла;
- **«Сохранять оглавление исходных файлов»** — закладки исходных документов
  перенесутся в результат.

**Изображения → PDF** — сделать PDF из фотографий или сканов
(JPG, PNG, BMP, TIFF, GIF, WEBP).

1. Нажмите «＋ Добавить изображения» или перетащите их в окно.
2. Порядок меняется кнопками «↑ Выше», «↓ Ниже» или «A→Я Сортировать»
   (по имени файла).
3. Выберите размер страницы: **«по размеру изображения»** или
   **«A4 с полями»** — картинка будет вписана в лист A4.
4. Нажмите «💾 Создать PDF».

Фотографии с телефона автоматически поворачиваются правильно.
Многостраничный TIFF (частый результат сканирования) превращается в несколько
страниц. У анимированных GIF берётся первый кадр — программа об этом сообщит.

### Страницы

**Удалить страницы** — впишите номера страниц, которые нужно убрать.
Программа заранее покажет, сколько страниц удалится и сколько останется.
Удалить все страницы нельзя. Удалённые страницы действительно исчезают
из файла — их текст нельзя будет извлечь из результата.

**Извлечь диапазон** — сохранить выбранные страницы отдельным файлом,
например нужную главу из большого отчёта.

**Повернуть страницы** — повернуть на **90° по часовой**, **90° против
часовой** или на **180°**. Оставьте поле страниц пустым, чтобы повернуть
весь документ. Пригодится для сканов, которые легли боком или вверх ногами.

**Порядок страниц** — расставить страницы по-новому. Номера пишутся в том
порядке, в котором страницы должны идти:

- `3,1,2` — третья страница станет первой;
- `10-1` — перевернуть документ из 10 страниц задом наперёд
  (кнопка «Обратный порядок» сделает это сама);
- `1,1,2` — страницу можно повторить.

Под полем видно, сколько страниц будет в результате, какие не войдут и
сколько повторов. Кнопка «Сбросить» возвращает исходный порядок.

**Разделить файл** — разбить документ на несколько файлов в выбранной папке:

- **каждая страница — отдельный файл**;
- **по N страниц в файле** — укажите N;
- **по закладкам верхнего уровня** — каждая глава оглавления станет
  отдельным файлом с её названием; страницы до первой закладки (обложка,
  введение) сохраняются отдельной частью «начало».

Перед запуском программа покажет, сколько файлов получится, и пример имён.
Нажмите «📂 Разделить и сохранить» и выберите папку.

### Документ

**Метаданные** — свойства документа: заголовок, автор, тема, ключевые слова,
приложение и производитель. Здесь же видны число страниц, размер первой
страницы в миллиметрах, даты создания и изменения.

- **«💾 Сохранить с метаданными»** — сохранить копию с исправленными полями
  (очищенное поле удаляется из документа);
- **«🧹 Сохранить без метаданных»** — сохранить копию, из которой удалены
  все свойства документа. Сведения внутри самих страниц и встроенных
  фотографий при этом не затрагиваются.

**Защита паролем** — поставить пароль или снять его.

- **«Установить пароль»**: введите пароль на открытие и повторите его.
  Без этого пароля документ не откроется. Используется надёжное
  шифрование AES-256.
- **Пароль владельца** (необязательно) запрещает изменять документ
  и копировать из него текст, но оставляет возможность читать и печатать.
  Он должен отличаться от пароля на открытие. Учтите: этот запрет соблюдают
  программы просмотра, от целенаправленного взлома он не защищает.
- **«Снять защиту»**: откройте защищённый файл (программа спросит пароль) —
  копия сохранится без пароля.

> **Забытый пароль восстановить невозможно.** Запишите его.

**Сжатие** — уменьшить размер файла без потери качества: программа сжимает
содержимое страниц и убирает повторяющиеся данные. Разрешение изображений
не меняется. Можно заодно удалить метаданные. После сжатия видно, сколько
было, сколько стало и процент экономии. Если документ уже был сжат
хорошо, файл может почти не уменьшиться — программа об этом скажет.

**Нумерация и водяной знак** — нанести на страницы номера или надпись.

Вкладка «Нумерация страниц»:
- **Формат**: `{n}` — номер страницы, `{total}` — всего страниц.
  Например, `{n}` даст «5», а `Стр. {n} из {total}` — «Стр. 5 из 12»;
- **Положение**: снизу слева, снизу по центру, снизу справа или сверху справа;
- **Начать с номера**, **размер шрифта**;
- **«Не нумеровать первую страницу (титульную)»**.

Вкладка «Водяной знак»:
- **Текст** — например, «КОПИЯ» или «ЧЕРНОВИК»;
- **Размер шрифта**, **наклон** в градусах;
- **Прозрачность** — от 0.05 (едва заметно) до 1.0 (сплошной цвет);
- **«Размещать под содержимым страницы»** — надпись окажется под текстом
  и не будет его закрывать.

Номера и надписи встают на своё место и на повёрнутых страницах.
Русский текст поддерживается: нужный шрифт встроен в программу.

### Экспорт

**Текст и изображения**

- **«📝 Сохранить текст (.txt)»** — весь текст документа (или выбранных
  страниц) в обычный текстовый файл. Флажок «Разделять страницы заголовками»
  отделяет страницы строками «───── Страница N ─────».
- **«🖼 Извлечь изображения»** — сохранить все картинки, встроенные
  в документ, в выбранную папку.

Текст можно извлечь только из документов, где он есть. Отсканированные
страницы — это картинки: текста в них нет, для этого нужно распознавание
(OCR). Программа сообщит, сколько страниц оказались без текста.

## Защищённые файлы

Если файл защищён паролем, программа спросит его один раз — при выборе
файла — и дальше будет использовать сама. Файлы, у которых есть только
запрет на изменение (без пароля на открытие), открываются без вопросов.

Результат любой операции, кроме «Защиты паролем», сохраняется **без защиты**.
Перед этим программа предупредит и спросит, продолжать ли. Если копия должна
остаться защищённой, после обработки поставьте пароль заново в разделе
«Защита паролем».

## Частые вопросы

**Окно перестало отвечать.**
Большой документ обрабатывается какое-то время, и окно на это время
замирает. Подождите: ход работы виден в строке состояния внизу окна.
Окно выбора по миниатюрам на документах в сотни страниц тоже открывается
не мгновенно.

**«Файл изменился после выбора. Выберите его заново».**
Исходный файл изменили или заменили, пока он был выбран в программе.
Нажмите «Выбрать…» и укажите его ещё раз.

**«Не удалось сохранить… Возможно, файл открыт в другой программе».**
Закройте файл в программе просмотра (например, в браузере или Adobe Reader)
и сохраните снова или выберите другое имя.

**Появилось окно «Внутренняя ошибка».**
Подробности записаны в файл журнала:
`%LOCALAPPDATA%\PDF Manager\errors.log`
(вставьте этот путь в адресную строку Проводника). Приложите файл, если
сообщаете об ошибке.

**Где сведения о версии и лицензиях?**
Кнопка «О программе» в правом верхнем углу. Там же — кнопка
«Тексты лицензий» со всеми лицензиями встроенных компонентов.

## Для разработчиков

Запуск из исходного текста (Python 3.10+; в Linux дополнительно нужен
пакет `python3-tk`):

```bash
pip install -r requirements.txt
python main.py
```

Обязательна только библиотека `pypdf`; без остальных программа работает,
а разделы, которым они нужны, подскажут, что установить.

Тесты: `pip install pytest`, затем `pytest tests` (в Linux без дисплея —
`xvfb-run -a pytest tests`).

Сборка `PDF Manager.exe` выполняется в Windows: запустите `build.bat`,
готовый файл появится в папке `dist`.

Значок программы (`assets/icon.png`, `assets/icon.ico`) рисует сценарий
`python tools/make_icon.py` из геометрических фигур, без шрифтов и чужих
изображений. После правки сценария запустите его заново и пересоберите
программу.
